Overview

The API allows users to create, retrieve, update, and delete records through secure HTTP requests. Use the endpoints listed below to integrate your system with the platform.

Authentication

Every request requires a valid API key passed in the request header.

Authorization: Bearer YOUR_API_KEY

Endpoint Example

GET /v1/customers/{id}

Returns a customer record including the account ID, status, and metadata.

Response Format

  • Status code: 200 for success
  • Content-Type: application/json
  • Response includes id, name, status, createdAt
